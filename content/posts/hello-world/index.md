## 嚏语开张了 🎉

你好！我是阿嚏，欢迎来到「嚏语」——我的个人小站。

这是博客的第一篇文章，简单聊聊为什么要搭建这个博客。

## 为什么叫「嚏语」？

> 打个喷嚏，说两句话。

轻松、随意，不必正经地坐在那里写长篇大论。就像打了个喷嚏一样自然——想到什么就记录什么。

## 这个博客是怎么搭的？

技术栈很简单：

- **Hugo** — 静态网站生成器，编译速度飞快
- **PaperMod** — 简洁优雅的主题
- **GitHub Actions** — 推送代码即自动部署
- **GitHub Pages** — 免费托管
- **Giscus** — 基于 GitHub Discussions 的评论系统

整个流程就是：

```
写 Markdown → git push → 自动部署 → 上线
```

完全零成本，体验极佳。

## 接下来写什么？

大概会有这些内容：

- 🛠️ **技术分享** — 开发中踩过的坑，有用的工具和技巧
- 💭 **随想** — 碎碎念，生活中的观察和思考
- 📚 **学习笔记** — 读书、学习新技术的记录

希望这里能成为一个有趣的小角落。
